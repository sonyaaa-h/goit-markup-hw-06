# First HTML & CSS Project

A responsive static website built using pure HTML5 and CSS3.  
This project demonstrates my understanding of semantic markup, structured styling, and modern layout techniques.

## 📌 Project Overview

The goal of this project was to build a clean, responsive webpage from scratch while following frontend best practices.  
The layout is fully adaptive and optimized for desktop, tablet, and mobile devices.

## 🚀 Key Features

- Semantic and accessible HTML structure  
- Organized and maintainable CSS  
- Responsive design implementation  
- Clean spacing, typography, and visual hierarchy  
- Cross-device compatibility  

## 🛠 Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Responsive Design Principles
